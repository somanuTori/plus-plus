




Категорія          Розширення
Текстові файли     .txt
Зображення         .jpg, .png, .bmp
Виконувані файли   .exe
Інші               усе решта


Крок 1. Прийом шляху до директорії

шлях передається через аргумент командного рядка;

перевіряється, чи існує директорія.

Крок 2. Рекурсивний обхід директорії

використовується recursive_directory_iterator;

обробляються лише файли, не папки.

Крок 3. Аналіз розширення файлу

розширення приводиться до нижнього регістру;

файл відноситься до відповідної категорії.

Крок 4. Акумуляція статистики

лічильники файлів;

сумарний розмір у байтах.

Крок 5. Виведення результатів

кількість файлів;

загальний обсяг пам’яті по категоріях.
